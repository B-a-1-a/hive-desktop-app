# Developer mode

Hive hides tools that only help with software development until you ask for them. Turn them on
in **Settings > General > Developer mode**. The setting applies to this device.

With developer mode off, Hive hides:

- the terminal, pull request, and device panels, and the terminal drawer
- the editor, project script, branch, Git action, and server rows in thread details
- the Source control, Worktrees, Diffs & pull requests, and Devices settings pages
- the Pull requests button in the sidebar, and the pull request and issue triage commands
- keyboard shortcuts for the terminal, pull requests, and editors

Files, the change review panel, the browser, scheduled tasks, and usage stay visible either way.
Turning developer mode off does not delete anything: your shortcuts, scripts, and choices for the
thread details card return when you turn it on again.
